# Navier

Simule un maquillage, crée tes routines et organise tes produits dans des listes.

[**Télécharger Navier.html**](https://github.com/himehitmann/Bty/releases/latest/download/Navier.html)

Une fois le fichier téléchargé, double-clique sur **Navier.html** pour ouvrir Navier dans ton navigateur.

Tu peux aussi retrouver le fichier dans [**Releases**](https://github.com/himehitmann/Bty/releases), sous **Assets** de la dernière version.

[Voir le code source et le guide de lancement](https://github.com/himehitmann/Bty/tree/codex/navier)
